# Multi-Agent System ｜ Advisor 周报

这是一个可直接编辑的周报模板，围绕 `Multi-Agent System` 和 `Advisor（小模型调用大模型）` 两条主线整理。

两条线的材料分别放在 `multi-agent-system/` 和 `advisor/` 子目录中，根目录保留双线合并版模板。

## 本地查看

直接用浏览器打开 `weekly-report-template.html`，点击带有占位文字的区域即可编辑。模板支持响应式布局，也支持浏览器打印或导出 PDF。

## GitHub Pages

GitHub Actions 会在推送到 `main` 分支后自动发布最新的 `weekly-report-template.html`。仓库首页会自动进入该模板。

页面内容完全由仓库内文件提供，不依赖外部字体、脚本或样式服务。
